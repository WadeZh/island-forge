# 一笔造岛 · ISLAND FORGE

> 画一条线，创造一个有生命的世界。

参加 WorkBuddy 2026「1024 造物挑战」的网页作品。用鼠标或手指画一条闭合的线，它会长成一座有沙滩、草地、森林、小屋、风车与灯塔的迷你小岛——有昼夜、有晴雨、有点得亮的窗户和转得飞快的风车。

## 在线体验

- 本地开发：`npm install && npm run dev`，浏览器打开 http://localhost:5173
- 本地预览生产构建：`npm run build && npm run preview`，打开 http://localhost:4173
- 线上链接：（发布后填写，见下文「发布」一节）

## 玩法

1. **画岛**：按住鼠标/手指在海上画一条闭合线，松手后自动闭合、简化、平滑并校验（太小、太窄、自交叉会被友好拒绝）。
2. **生成**：6 阶段动画——轮廓发光聚水 → 沙滩升起 → 草地生长 → 树木花草 → 建筑落成 → 万物活动。
3. **探索**：
   - 切换 **白天/夜晚**：夜晚窗户亮灯、灯塔扫射海面、萤火虫飞舞、海面有月光反射。
   - 切换 **晴天/雨天**：雨幕、海面涟漪、整体色调变冷。
   - **重新装点**：保持你的海岸线不变，换一套随机种子重新布置树木、房屋与花草。
   - 点击 **树（落叶）、小屋（亮灯冒烟）、风车（加速）、小船（摇曳）、灯塔（亮灯）、礁石（回声）**，每种实体都有反馈。
4. **保存**：生成 1600×1200 高清分享海报（岛屿画面 + 名字 + 介绍 + 品牌 + 日期），可下载 PNG 或系统分享；最近一次小岛自动存入 localStorage，下次可「回到我的小岛」。

### 彩蛋与趣味系统

- **岛屿代码 · 拜访系统**：导出弹窗一键复制你岛屿的专属代码（纯离线压缩，约 130 字符），朋友在首页「用岛屿代码拜访」粘贴即可登岛做客——无需服务器、无需登录。拜访态有专属横幅与「回到我的岛」。
- **岛民小剧场**：每座小屋走出一名散步居民（在岛上闲逛发呆，入夜回家）；有码头必配一名钓鱼翁（斗笠+鱼竿+浮标，偶发收竿水花）。点击岛民会打招呼。
- **岛屿之歌**：旋律由你的轮廓生成——从岛心向 16 个方向测距映射到五声音阶，同一座岛永远唱同一首歌。生成完成自动演奏，顶栏 ♪ 随时重播。
- **黄昏与时光流逝**：时间三态（白天→黄昏→夜晚），黄昏有夕阳金光晕与暖色海面、小屋提前亮灯；「时光流逝」开关让昼夜自动循环。
- **形状彩蛋**：心形（IoU ≥ 0.72）粉花海；五角星（IoU ≥ 0.62）解锁「摘星屿」+金色花朵+夜间流星。
- **岛屿评级**：S/A/B/C 显示在生成名牌与分享海报上。
- **成就系统**：13 个成就 + 连击 Combo + 徽章墙，进度持久化。
- **声音**：Web Audio 实时合成——海浪、雨声、实体音效、岛屿之歌、成就铃音，可静音。
- **小剧场**：海豚跃出海面、飞鸟掠过、蝴蝶绕花、雨后彩虹、星形岛流星；**点击草地亲手种花**（上限 30 朵，永久保留）；海面漂来**漂流瓶**，捞起读一封瓶中信；**雪天**让小岛覆上薄雪；面积恰好 1024×100 的岛获「1024 造物纪念」角标，每天第一座岛是「今日之岛」。

## 技术方案

- **Vue 3 + TypeScript + Vite**，无付费 API、无后端、无账户体系，全部核心逻辑在浏览器内完成。
- **Canvas 2D** 渲染：1200×800 逻辑坐标 contain 适配任意视口，DPR 上限 2。
  - 静态地形（沙/草/纹理/花草）绘制进离屏画布缓存，动态层（海洋、实体、粒子、天气）按帧更新。
  - 草地与沙滩的分层使用「填充 + 多级 destination-out 内蚀」的剪裁式方案，稳定处理任意凹多边形。
- **GSAP** 驱动生成时间轴与界面转场；渲染循环 `requestAnimationFrame`，页面隐藏自动暂停，帧时长 EMA 自适应降低粒子与波纹数量。
- **几何管线**（`src/geometry/`）：采样去重 → RDP 简化 → 闭环自交拆解（取面积较大环）→ Chaikin 平滑 → 面积/宽度校验。
- **程序化生成**（`src/generation/`）：mulberry32 可复现种子；候选点 → 点在多边形内 → 边缘最小距离 → 圆形碰撞 → 有上限的尝试放置；同一轮廓 + 同一Decoration种子 ⇒ 完全相同的布局。
- **测试**：Vitest 覆盖几何与布局（43 用例）；Playwright 覆盖桌面/手机/小屏三种视口的完整用户流程（绘制、生成、昼夜晴雨、交互、PNG 下载校验、重新造岛、localStorage 恢复）。

## 目录结构

```
src/
  components/   欢迎页、绘制面板、生成名牌、探索控制、导出弹窗
  engine/       Canvas 渲染：海洋/地形/实体/特效/场景编排/海报
  geometry/     轮廓简化、平滑、面积、点在多边形内、自交修复、校验
  generation/   随机种子、布局放置、命名、心形识别、示例轮廓
  effects/      粒子与天气（涟漪/烟/落叶/萤火虫/雨）
  utils/        localStorage 存储、PNG 导出与系统分享
  tests/        Vitest 单元测试
e2e/            Playwright 浏览器流程测试
```

## 常用命令

```bash
npm install          # 安装依赖（含 Playwright 需 npx playwright install chromium）
npm run dev          # 开发服务器
npm run build        # vue-tsc 类型检查 + vite 生产构建
npm run preview      # 预览生产构建（4173 端口）
npm run test         # Vitest 单元测试
npm run e2e          # Playwright 浏览器测试（自动启动 preview）
```

## 发布

`npm run build` 产出纯静态 `dist/`，可部署到任何静态托管（Vercel / Netlify / GitHub Pages / 对象存储）。`vite.config.ts` 已配置 `base: './'`，支持任意子路径。

## 无障碍与适配

- Pointer Events 统一鼠标与触屏，画布 `touch-action: none` 防止误滚动。
- 桌面端控制面板悬浮于右侧并显示文字标签；移动端自动变为底部工具条，顶部信息避让安全区。
- 所有交互均有视觉反馈；无登录、无 API Key、无付费依赖。
